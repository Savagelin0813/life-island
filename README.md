# 我的生活島

把日常瑣事排成六角形小島的 3D 互動網頁。每座島是一個生活面向，島上的小屋是一件瑣事。

## 功能

- 拖曳旋轉、雙指縮放，點小屋看細節並標記完成（完成後屋頂會插旗）
- 關鍵字搜尋，符合的小屋會放大發亮
- 日夜循環與時間滑桿，夜晚窗戶亮燈
- 小人偶依序走訪各座島
- 瑣事之間的「協作線」，點小屋可看到相關項目
- 新增自己的瑣事（每座島最多 6 件），完成狀態與新增內容存在瀏覽器的 localStorage

## 使用

單一 `index.html`，不需要建置。直接用瀏覽器開啟，或用任何靜態伺服器提供檔案即可。

## 修改內容

資料集中在 `index.html` 裡 `DATA` 區塊：

- `islands`：每座島的名稱、顏色、草地色與瑣事清單（第一座是中央的日常基地，其餘六座依序環繞）
- `links`：瑣事之間的協作線，格式為 `[起點 id, 終點 id, 說明]`
- `defaultDone`：第一次開啟時預設已完成的項目

## 技術

- [Three.js](https://threejs.org/) r128（由 jsDelivr CDN 載入）
- OrbitControls、CSS2DRenderer（Three.js 官方範例模組）
- 純原生 JavaScript，無建置工具

所有範例資料皆為虛構。
